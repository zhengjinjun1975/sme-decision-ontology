# 架构文案补充：v0.12 定位评估 + 竞品差异化 + 产品化建议

> 2026-08-07 ｜ sme-decision-ontology v0.12 ｜ 作为 docs/企业级决策方法论评估.md 的补充，面向未来产品化

## 一、v0.12 优缺点说明（150 字）+ 企业用途

**优点**：轻量（单进程/零 token/本地可部署）；本体驱动、确定性规则可解释（规则算，LLM 讲）；跨行业泛化（阀门/食品自适应）；决策执行闭环 + LLM 兜底。
**缺点**：覆盖进销存+运维预警型决策，非优化型（排程/定价）；无执行端业务记录（不做 ERP）；LLM 摘要/问答依赖本地 Ollama 或云端 key，离线但算力弱。
**企业用途**：中小企业把台账（CSV/Excel/数据库）接入，得到补货/缺货/呆滞/账期/设备维护等**确定性决策建议 + 行动清单**，替代"拍脑袋"，可落地。

## 三、核心差异化（本项目独有组合）

1. **决策建议层，非 ERP/知识库**：只做"决策"（预警/提示/行动清单），不记录业务、不做文档问答——填补 ERP 与知识库之间的空档
2. **本体驱动 + 确定性可解释**：进销存+运维价值链条本体（实体/关系/约束），规则引擎零 token 确定性，LLM 只解释/兜底（"规则算，LLM 讲"）
3. **跨行业泛化**：换数据换 schema 自动新建模，已验证阀门/食品两行业（同类多为固定行业）
4. **轻量落地**：单进程 + Docker，本地离线可用，无重型框架（不引 OWL/RDF/SPARQL）
5. **决策执行闭环**：行动清单→完成→阈值自适应；LLM 参与建模/问答/摘要（完整模型闭环，云端无 key 明确报错）

## 四、未来完全产品化建设性建议（架构补充）

**阶段一（产品化基础）**：
1. **执行端打通**：决策建议 → 一键生成 ERP 单据/推送钉钉飞书企微（对齐 qKnow 的 IM 打通）
2. **数据源深化**：真实 ERP/数据库全量接入（Odoo/金蝶 API）、增量同步、数据血缘
3. **决策优化升级**：EOQ 最优补货量、简单生产排序（纯规则，不上 ML 保轻量）

**阶段二（差异化护城河）**：
4. **跨行业本体模板库**：阀门/食品/机械等预置 schema + 决策规则，一键切换（对标行业化）
5. **决策效果看板 + 闭环度量**：行动→效果→ROI 追踪，证明决策价值（产品化关键卖点）
6. **多租户 + 角色权限**：企业内部分部门/角色决策视图（对标 ERP 多用户）

**阶段三（AI 原生深化）**：
7. **本体建模成熟度**：LLM 从 label 增强 → 主动建议实体/关系/约束（人拍板），AI 原生建模自动化
8. **预测升级**：需求预测（可选 ML 插件，不破坏零 token 确定性内核）
9. **SaaS 化打包**：容器化一键部署 + 云端托管选项（本地/云双模式）

**建设性判断**：本项目已在"决策建议层"这一差异化空档站稳（非 ERP 非知识库）。产品化核心是**打通执行端（让决策真正落地）+ 跨行业模板 + 效果闭环度量**——这三点能把"预警工具"升级为"可度量价值的决策产品"。
