## 二、逐项说明（本项目 vs 各竞品的差异点）

### 1. 数据驱动决策建议
- **本项目**：✓ 直出确定性决策建议（补货/缺货/账期/维护）+ 行动清单
- Odoo/ERPNext/InvenTree/金蝶/中台：△ 报表/看板为主，需自己分析或二次开发
- qKnow：✗ 是知识问答，非决策建议
- Palantir：✓ 完整决策应用

### 2. 本体建模
- **本项目**：✓ 跨表语义本体（实体+关系+约束+类型体系+属性语义角色）
- Odoo/ERPNext/InvenTree/金蝶/中台：✗ 字段级业务对象/主数据，非语义本体
- qKnow：△ 知识图谱（文档组织），非决策本体
- Palantir：✓ 完整企业本体

### 3. 跨行业泛化
- **本项目**：✓ 已验证阀门(178节点)+食品(43节点)，换 schema 即用
- Odoo/ERPNext/金蝶/中台：△ 通用但每行业需配置定制
- InvenTree：✗ 制造/库存单域
- qKnow/Palantir：✓ 通用

### 4. 决策执行闭环
- **本项目**：✓ 行动清单→完成→效果追踪→阈值自适应（唯一完整闭环）
- 其余：✗ 无（Palantir △ 部分）

### 5. LLM 参与
- **本项目**：✓ 本体建模生成中文label + 问答兜底 + 决策摘要（本地Ollama/云端DeepSeek，完整模型闭环）
- qKnow：✅ RAG 问答；金蝶：✅ AI 助手
- Odoo/ERPNext/InvenTree：✗ 社区版无

### 6. 确定性可解释
- **本项目**：✓ 每条建议带公式（如 D1补货: stock<再订货点=(日均×提前期+安全库存)），可审计
- Palantir：△ 部分；其余：✗（LLM 黑盒/报表无公式）

### 7. 轻量部署
- **本项目**：✓ 单进程 + Docker，秒起，本地离线
- InvenTree：✅ 轻量；Odoo/ERPNext/中台：✗ 重；Palantir：✗ 重资产

### 8. 中小企业适配
- **本项目**：✓ 专为 SME（轻量/零token/本地/免重型框架）
- Palantir：✗ 大企业（贵/重）；金蝶：✅ SaaS 即用；Odoo/ERPNext：△ 实施成本高

## 三、定位结论

```
        业务记录层 (ERP)             决策建议层 (本项目)              知识/数据层
   Odoo / ERPNext / InvenTree  →  sme-decision-ontology  →   qKnow / 数据中台
         ↑ Palantir(重型完整)             ✅ 12/12 全占
```

**本项目独特组合**：`决策建议 + 本体建模 + 跨行业 + 执行闭环 + LLM参与 + 确定性可解释 + 轻量本地开源`——这在 Odoo/ERPNext（无决策层）、qKnow/中台（非决策）、Palantir（重贵）、金蝶（闭源云）中**无同类竞品**。差异化护城河 = **轻量本体驱动的确定性运营决策**，填补中小企业"买不起 Palantir、玩不转 ERP/知识图谱"的空档。
