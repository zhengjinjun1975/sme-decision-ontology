# 竞品对比：sme-decision-ontology v0.12 vs 社区同类

> 2026-08-07 ｜ 分项目逐一对照 ｜ 定位：中小企业"决策建议层"（非 ERP、非知识库）

对比维度：定位 / 部署体量 / 决策能力 / 本体建模 / 行业覆盖 / 成本 / 开源 / 差异化

---

## 一、Odoo（Apache-2.0，GitHub 53.5k★）

- **定位**：一体化开源 ERP（进销存+财务+CRM+HR+制造，全模块）
- **部署**：重量级（Python 框架 + PostgreSQL + 大量模块安装配置）
- **决策能力**：报表/看板为主，规则有限，需二次开发；无"决策建议层"
- **本体建模**：业务对象（模型/字段），非本体（无跨表语义关系/约束/类型体系）
- **行业覆盖**：通用，但每行业需大量配置定制
- **成本**：免费社区版，但实施/配置成本高
- **开源**：LGPL/AGPL（社区版）

**与本项目差异**：
- 本项目**只做决策建议层**（补货/缺货/账期/维护预警 + 行动清单），不替代 Odoo 记录业务——是 Odoo 之上的"决策脑"，非其替代品
- 本项目**轻量**（单进程 + Docker，秒起），Odoo 重部署
- 本项目**跨表语义本体 + 确定性规则**，Odoo 是字段级业务对象
- **互补定位**：本项目可对接 Odoo 数据源，做决策层

## 二、ERPNext（GPL-3.0，37.7k★）

- **定位**：开源 ERP（Frappe 框架，进销存+财务+CRM）
- **部署**：中等（Frappe 架构，需 bench 安装）
- **决策能力**：报表/仪表盘，规则有限
- **本体建模**：DocType（文档类型），非本体
- **行业覆盖**：通用，垂直行业需定制
- **成本**：免费，但实施成本高
- **开源**：GPL

**与本项目差异**：
- 同为开源轻量 ERP，但**本项目专注"决策"而非"记录"**——ERPNext 管业务操作，本项目管"要不要补货/该不该催收/设备该不该修"
- 本项目**跨行业自适应**（阀门/食品换 schema 即用），ERPNext 换行业要重新建模定制

## 三、InvenTree（MIT，7.35k★）

- **定位**：开源库存+制造管理（InvenTree 单域）
- **部署**：Django，轻中量
- **决策能力**：库存报表/低库存预警，单域
- **本体建模**：无本体（库存表结构）
- **行业覆盖**：制造/库存
- **成本**：免费
- **开源**：MIT

**与本项目差异**：
- 本项目**跨全价值链**（采购/生产/库存/销售/财务/运维），InvenTree 仅库存+制造单域
- 本项目**决策闭环**（行动→完成→阈值自适应），InvenTree 仅低库存提示

## 四、qKnow / 千知知识图谱平台（开源，新兴）

- **定位**：企业知识图谱 + RAG 知识库 + 大模型问答，打通钉钉/飞书/企微
- **部署**：前后端分离，需服务端
- **决策能力**：知识检索/问答，**非决策建议**
- **本体建模**：概念/关系抽取规则（知识组织）
- **行业覆盖**：通用知识管理
- **成本**：免费
- **开源**：开源

**与本项目差异**：
- 本项目是**决策驱动**本体（实体+关系+约束+决策规则→确定性建议），qKnow 是**知识组织**（文档→图谱→问答）
- 本项目输出**可执行决策建议 + 行动清单**，qKnow 输出知识答案
- **互补**：qKnow 做企业知识底座，本项目做运营决策

## 五、Palantir Ontology（商业）

- **定位**：企业级数据融合→本体→决策 App（重型完整决策平台）
- **部署**：企业级云/私有化，重资产贵
- **决策能力**：完整（数据→本体→语义→决策应用）
- **本体建模**：完整企业本体（对象/属性/链接/语义）
- **行业覆盖**：大型企业通用
- **成本**：高（授权+实施）
- **开源**：否

**与本项目差异**：
- 本项目是 **Palantir 的 SME 轻量版**：同样的"数据→本体→决策"范式，但**单进程零 token 本地免重型框架**，适合中小企业
- Palantir 重资产贵，本项目轻量开源——**填补中小企业"买不起 Palantir"的空档**

## 六、金蝶 AI 星辰（商业 SaaS）

- **定位**：中小企业财务/管理软件 + AI
- **部署**：云 SaaS
- **决策能力**：财务/管理报表 + AI 助手
- **本体建模**：财务科目/业务模型，非本体
- **行业覆盖**：通用中小企业
- **成本**：订阅付费
- **开源**：否

**与本项目差异**：
- 本项目**本地开源**（数据不出企业），金蝶云 SaaS
- 本项目**确定性规则可解释**（每条建议带公式），金蝶 AI 星辰偏云端大模型
- **互补**：本项目可对接金蝶财务数据做经营决策

## 七、轻量数据中台（新兴）

- **定位**：数据驱动决策的中台工具
- **部署**：中台架构，偏重
- **决策能力**：数据整合→看板，需自己写分析
- **本体建模**：数据治理/主数据，非决策本体
- **行业覆盖**：通用
- **成本**：中高
- **开源**：部分

**与本项目差异**：
- 本项目**直出决策建议**（不需要数据团队写分析），数据中台给数据但"决策最后一公里"靠自己
- 本项目**零 token 确定性规则**，数据中台偏 BI 可视化

---

## 结论：本项目独特定位

```
        业务记录层 (ERP)             决策建议层 (本项目)              知识/数据层 (知识图谱/中台)
   Odoo / ERPNext / InvenTree  →  sme-decision-ontology  →   qKnow / 数据中台
```

**填补空档**：中小企业既不需要重量级 ERP 的"记录"，也难驾驭知识图谱/数据中台，更买不起 Palantir——本项目用**轻量本体 + 确定性规则**直出可执行的运营决策建议，这是差异化护城河。
